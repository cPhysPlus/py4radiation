Installation
============

It is highly recommended to install this package in editable mode during development.

This ensures that any modifications to the source scripts are instantly available without requiring reinstallation.

Run the following command from the repository root (where pyproject.toml is located):

.. code-block:: bash

   git clone https://github.com/cPhysPlus/py4radiation.git
   cd py4radiation
   python -m pip install -e .
