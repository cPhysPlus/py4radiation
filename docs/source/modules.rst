API Reference
====================

The py4radiation API is organised into three subpackages:

- ``radiation``: Generation and processing of spectral energy
  distributions and Cloudy parameter files.
- ``pyciao``: Configuration, task management and parallel
  execution of Cloudy calculations.
- ``utils``: Retrieval of reference spectra and processing
  of heating, cooling and ionisation-fraction tables.
