API Reference
=============

The py4radiation API is organised into three subpackages:

* ``radiation``: Preparation of spectral energy
  distributions and Cloudy parameter files.
* ``pyciao``: Configuration, task management and
  execution of Cloudy calculations.
* ``utils``: Retrieval of reference spectra and
  processing of numerical tables.
