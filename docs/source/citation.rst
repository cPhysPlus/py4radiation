Citation
========

If you use py4radiation in your research, please acknowledge
the software and cite the relevant scientific references.

Scientific references
---------------------

The framework incorporates or interfaces with several
scientific models and codes.

The relevant references should also be cited when these
components are used.

DOI: 10.1088/0004-637X/746/2/125

The 2013 Release of Cloudy.
